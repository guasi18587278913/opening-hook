# 开头写法索引

这里只帮助找方法。选中后读取 [完整资料](wiki-opening-hook.md) 对应条目，或运行 `python3 scripts/read_methods.py 编号...`；不要用索引替代方法的材料条件、变体、原例和风险。

按六类快速看一遍，寻找当前材料里有依据的入口；不用每次写满所有方法。下面列出的分支是检索提示，部分原例有夸张、情境限制或只有视频用例，采用前以完整条目和当前材料判断。

| 编号 | 写法 | 识别线索与容易漏掉的变体 |
|---|---|---|
| 1 | 反着说，打破常识 | 真反对已有说法；我以为／结果；反常愿望再解释 |
| 2 | 前后对比、高低反差 | 前后状态、身份与待遇、熟悉参照、成果接过去吃亏 |
| 3 | 不对劲的人和事 | 身份／行为、东西／地点、时间错位、人物关系倒过来 |
| 4 | 出人意料的结果 | 让人问为什么；重大决定配轻微原因、付出与结果错位 |
| 5 | 嘴上反着说 | 假差评、假劝退、凡尔赛式诉苦、抱怨着夸、假曝光 |
| 6 | 冲突对立、争议话题 | 真实分歧、受到质疑、犀利问题、目标与阻力 |
| 7 | 直接下判断 | 明确立场、带梗判断、负面预判、从真实表达提炼观点 |
| 8 | 稀罕东西、少见手艺 | 少见对象、传承与消失、奇特制作细节 |
| 9 | 悬念：只说一半 | 确有答案；待解释的事、对赌、贯穿长文的小物件 |
| 10 | 提问 | 真想知道的问题；条件推演、为什么却、凭什么、二选一 |
| 11 | 揭秘内幕 | 有来源的少见信息；行规、假如说真话、排除表面答案 |
| 12 | 抛一个没听过的新词 | 给常见现象命名、熟词变体、立即解释 |
| 13 | 亲测、挑战、盲盒 | 花钱验证、时间难度关卡、随机条件、首次尝试、踩雷 |
| 14 | 先交代有多难 | 对象难处理、直观难度对比、真实限制 |
| 15 | 点名目标人群 | 直接点名、反向劝退、先大后小、自报同类身份 |
| 16 | 说出处境和痛点 | 具体任务卡点、难以继续、某时才意识到的困境 |
| 17 | 替大家吐槽 | 真不满；熟人抱怨、具体槽点、好笑的比喻 |
| 18 | 替读者说话、说他爱听的 | 替人提诉求、重新看待在意的缺点；归责须有事实依据 |
| 19 | 警告：不这样做会吃亏 | 真避坑、后果与条件、别做除非、替代做法 |
| 20 | 直接说能得到什么 | 具体所得、减少门槛、正文确有的方法或清单 |
| 21 | 开门见山，第一句就是选题 | 直接进入主题、具体行动、产品为谁解决什么 |
| 22 | 先亮结果 | 让人问怎么做到；小成就、阶段成果、成品先上 |
| 23 | 报一个扎眼的数字 | 价格、付出、规模、大小对照、数字与具体事情的反差 |
| 24 | 省钱、平替、花小钱 | 真实平替、后悔白花钱、日常省钱、价格对照 |
| 25 | 不推热门，推私藏 | 先排除热门，再说私藏与筛选；公认标杆、可获得性 |
| 26 | 让人羡慕的生活 | 真实向往场景、令人羡慕的事件或生活方式 |
| 27 | 开口就叫人去做 | 小行动、留意某事、其他可不带但这一件值得带 |
| 28 | 一句带情绪的感叹 | 真实强感受、后悔没早知道、具体使用情境 |
| 29 | 自曝短处、先认错 | 自己的错、真实弱点、难以启齿但确实有过的念头 |
| 30 | 开局就惨 | 真实打击、坏结果与影响；区分遭遇记录与有后续应对的完整故事，不编逆袭 |
| 31 | 从一个场景或一句对话切进去 | 原话、聊天记录、当下动作、别人发问、称呼开场 |
| 32 | 换个人来讲 | 第三人称讲自己、孩子／动物视角、专业人士的观察位置 |
| 33 | 先立 flag，等着打脸 | 当初真说过的大话、后来与之矛盾的事实 |
| 34 | 权威背书、晒人气 | 相关身份与年限、真实同款、行内视角、自嘲式资历、现场 |
| 35 | 蹭热点 | 有实际关注证据的近期事件、圈内讨论、热点消费参照；只有日期时可做事件引题，不算热度验证 |
| 36 | 借爆款的开头 | 有表现依据的同类参考，拆表达动作、句式和前两句关系；无数据仍可借普通参考，不算爆款验证 |
| 37 | 系列固定开场白 | 已有系列句、阶段标识、上一期问题、当期新信息 |

六类范围：**抛反常 1–8；吊胃口 9–14；说中读者 15–19；给好处 20–28；讲自己和故事 29–33；借势 34–37。**

特别容易混淆的几组：1／5／7，4／22，9／10／11，13／14，15／16，16／17／18／19，20／21，24／25，29／30／31，34／35／36。以当前材料和读者会产生的问题来分，不为覆盖编号生造差别。

视频配合不算文字写法：`--video` 读取“画面和动作先上”“最精彩的几秒剪到最前面”。`--gaps` 读取长文适配和来源较少的边界；`--common` 读取通用禁忌。只有覆盖验收时才用 `--all` 通读总清单。
