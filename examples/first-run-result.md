# opening-hook 首次使用产物

以下按面向社区小店经营者的口播来写。材料是本次测试的合成示例，三个版本都不预先承诺改动有效；没有现成全文，下面的接句是建议写法。

## 主推：从具体改动进入

小林重新分了社区书店的书架：
预约书、待归还的书，各放一区。
预约书上，再写上取书日期。

**怎么接正文：** 接“原来这两类书放在同一个书架，店员常要逐本核对。”再交代一周试行记录，以及没有改动前统计、还不能比较出错率的限制。

**为什么主推：** 这份材料最扎实的是做法本身。先把两项动作说清楚，观众马上知道这次调整是什么，不必靠尚未证明的收益吸引人。

## 备选一：从店员的核对负担进入

预约书和待归还的书放在一起，
店员常得逐本核对。
这家社区书店，就碰上了这个麻烦。

**怎么接正文：** 接“小林把书架分成两区，又在预约书上写了取书日期。”然后如实交代试行记录。

**这一版让人继续了解什么：** 面对逐本核对这个具体麻烦，小林采取了什么应对。只说这家店已提供的处境，不把它说成所有书店的共同经历。

## 备选二：从试行记录能说明什么进入

书架分区后，一周记录到一次取错书。
凭这一条记录，能说改动有效了吗？

**怎么接正文：** 接“还不能。店里没统计改动前取错过几次，所以暂时比不出出错率。”再回到小林做的两项调整，交代这次试行的经过。

**这一版让人继续了解什么：** 同一个试行记录，为什么还不足以证明效果。后文要先回答这个问题，不能把答案一直拖到结尾。

## 这次用了什么

- 开门见山 → “小林重新分了……” → 先交付最具体的操作，后面再补原来的问题和试行记录。
- 说出具体处境 → “店员常得逐本核对” → 从这家店已发生的工作麻烦进入；只采用处境写法，不声称已证明这是普遍痛点。
- 提问 → “凭这一条记录……” → 把重点放在证据能支持多大结论，正文有明确答案。

## 自查

三个入口分别前置操作、原来的核对任务、效果判断。前两个仍围绕同一项书架调整，适合比较“先说做法”与“先说麻烦”的开场偏好；第三个的关注问题明显不同。没有捏造店员身份、耗时、成本或前后出错率；这些版本尚无真实受众表现证据。
