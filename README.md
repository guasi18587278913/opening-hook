# 开头写法（opening-hook）

根据想法、素材或现稿选择合适的开场方式，生成或优化开头及必要衔接。

本仓库包含完整技能入口及所需的本地脚本和参考文件。使用流程从 [SKILL.md](SKILL.md) 开始。

## 获取与使用

```bash
git clone https://github.com/guasi18587278913/opening-hook.git
```

仓库根目录就是技能目录。将整个目录放入所用客户端的技能目录；保留目录结构，不只复制 SKILL.md。已有同名技能时，先检查本地修改再合并。

调用示例：`用 opening-hook，根据我提供的材料完成开头写法任务。`

实时 Wiki 读取需要自行配置 gbrain_sc_media 或 sc-media-kb 只读 MCP。本地参考文件可用范围以 SKILL.md 为准。
